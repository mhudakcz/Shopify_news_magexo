## O čem to je

Článek na Shopify blogu srozumitelně vysvětluje, co je Git a co GitHub, a proč se tyto nástroje hodí i lidem mimo vývojářský tým. Git popisuje jako open-source systém pro správu verzí běžící lokálně, zatímco GitHub jako cloudovou nadstavbu, která Git hostuje online a přidává vrstvu pro spolupráci — sdílení kódu, komentáře a přehled historie změn.

Text prochází základní pojmy krok za krokem: repozitář jako úložiště projektu se zdrojovým kódem a historií úprav, commit jako jednotlivé uložení změny s popisem a autorem, branch jako oddělenou verzi projektu pro bezpečné testování a pull request jako mechanismus pro kontrolované sloučení změn zpět do hlavní větve. Zmiňuje i Issues pro hlášení chyb a sledování úkolů. Jako praktické use cases uvádí týmovou spolupráci bez rizika kolizí v kódu, testování nových funkcí bez ohrožení živého obchodu, automatizaci pomocí GitHub Actions a hostování statických webů přes GitHub Pages. Na závěr nabízí jednoduchý návod na první kroky — instalace GitHub Desktop, registrace, vytvoření lokálního repozitáře — s odhadem, že celý proces zabere méně než 30 minut.
